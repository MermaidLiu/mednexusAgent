# MEDCARE

医生健康班与 AI 医患服务工作台（品牌 **MEDCARE**）。依据用户提供的横方健康产品方案实现，为独立产品原型，非横方原系统复制。

这是可运行、带数据库的业务原型。原 PPT 是业务介绍，不包含完整 UI、源代码或供应商接口，因此本项目不是横方原系统的逐像素复制，也不包含其专有模型。初始患者和趋势图均为明确标记的演示数据。

## 已实现

- 中文医生工作台、动态待办和患者/审核/随访统计。
- 患者建档、档案修改、关键词搜索、管理阶段和健康班分组。
- 创建健康班并查看成员。
- 咨询录入、服务模板草稿；配置 OpenAI 兼容服务后可生成模型草稿，并传入医生知识库。
- 医生编辑、通过/退回咨询及内容；状态由服务器校验，禁止重复审核。
- 随访计划、日期、患者绑定、实际结果记录、完成状态筛选。
- 科普文章、数字人脚本、就诊通知、感谢信的创建、审核与文件导出。
- 医生知识库、医生资料、工作空间 JSON 导出、操作审计。
- D1 持久化、按平台身份隔离数据、乐观锁保护并发写入、输入校验、错误恢复。
- 桌面和移动端适配；WebMCP 提供工作区导航工具。
- **双端入口**：`/` 选择医生端或患者端；医生工作台 `/doctor`，患者服务 `/patient`（演示，无需登录即可与数字人对话）。
- 全平台统一数字医助 **王主任**（2D 原图 + 右下角 3D 形象）。

## 尚未接入

企业微信消息接收/发送、患者端与医生端账号打通、医院挂号/加号/床位/报告系统、真实数字人形象和声音训练、视频合成、短信/微信自动提醒均未接入。界面不声称上述任务已执行。审核通过仅保存，不会发送消息或完成医院预约。数字人工作室目前管理脚本和内容，不生成视频。

外部连接需要医院和供应商接口、授权及凭据。对真实患者开放前，还需实施机构/医生/运营/患者角色权限、机构隔离、数据保留与备份、同意管理和部署环境安全评审。当前平台用户拥有自己的单人工作空间，不能直接作为多医院生产系统。

## 技术栈

React 19、TypeScript、Vinext/Vite、Tailwind CSS 4、Shadcn/Radix、Cloudflare Workers + D1、Drizzle 迁移。数据库以每位登录用户一条版本化工作空间记录保存，适合原型和小型工作区；规模化前应拆分患者、咨询、随访、审计等关系表并增加分页。

## 本地运行

需要 Node.js 22.13+（推荐 Node.js 24）及 npm。

```sh
npm ci
npm run db:local
npm run dev
```

打开 http://localhost:5173 选择 **医生端** 或 **患者端**。医生端需点击“登录工作空间”；患者端可直接咨询王主任。开发服务器仅在回环地址提供模拟登录，生产环境不使用本地身份。第一次登录会创建 12 位虚构患者供体验，数据保存在 `.wrangler/state`，不会提交到 GitHub。

```sh
npm test
npm run typecheck
npm run build
```

首次迁移通过 `npm run db:local` 执行并记录，之后新增迁移时重复运行即可。建表操作不会在 API 请求中执行。

## 模型配置

默认没有外部模型，不消耗 API 额度。咨询采用明确标注的服务模板。需要真实模型时，在服务端设置 `LLM_API_KEY`、`LLM_MODEL` 和可选 `LLM_BASE_URL`（HTTPS 的 OpenAI 兼容 API 前缀）。本地可将这些值加入未跟踪的 `.dev.vars`，生产用平台密钥管理。接口调用路径为 `<LLM_BASE_URL>/chat/completions`，密钥不会传给浏览器。

模型只能生成草稿；个性化诊疗信息需医生审核。开启模型后，录入的问题与最多 20 条知识库内容会发给所配置的服务商，部署者应确保输入范围和授权适当。系统不会自动发送患者姓名、联系电话或完整档案。

## 身份与部署

API 要求受信任网关提供 `oai-authenticated-user-id`。Sites 的私有部署负责身份验证，开发用 `build/sites-vite-plugin.ts` 的回环模拟登录。所有数据按该身份隔离；POST 校验同源 Origin；写入使用 D1 条件更新进行版本检查，冲突返回 409，并保留界面输入。

如自行部署到其他云平台，必须替换身份层或只允许受信任且会覆盖身份头的网关访问，不能将接受客户端自报身份头的 Worker 直接公开。`.openai/hosting.json` 包含当前 Sites 项目绑定；复制本项目时应使用自己的项目绑定。

Sites 部署需上传构建产物并应用 `drizzle/` 迁移。GitHub 提交不等同于自动部署，仓库的 CI 会运行测试、类型检查和构建。

## 数字医助王主任

医生端与患者端统一称呼与形象 **王主任**（MEDCARE 数字医助，AI 虚拟助手，非线下真人本人）。左侧「数字人对话」使用卡通医生原图（`public/avatars/mednexus-doctor.jpg`），2D 待机动效与浏览器朗读同步，无嘴型合成或声音克隆。支持多轮文字、快捷问题、朗读、自动朗读、停止生成与新对话。对话保存在页面内存，切换页签保留、刷新清空。

未配置模型时，界面与回复标为演示模式。配置 `.dev.vars` 的 `LLM_API_KEY`、`LLM_MODEL`、`LLM_BASE_URL` 后走 OpenAI 兼容多轮对话；患者端 `/api/avatar-chat` 在未登录时也可使用（`audience: patient`）。模型调用失败会报错，不伪装为 AI 回答。

语音由浏览器 SpeechSynthesis 提供；自动朗读默认关闭。未接入语音识别。

右下角浮窗在医生端（登录后）与患者端均可用。医生端侧重资料整理与待复核清单；患者端侧重就医疑问与复诊准备。不自动读取患者档案；启用模型时用户文字会发往所配置服务。
医学背景参考：NCI 卵巢上皮癌 PDQ（https://www.cancer.gov/types/ovarian/patient/ovarian-epithelial-treatment-pdq）及生物标志物检测说明（https://www.cancer.gov/about-cancer/treatment/types/biomarker-testing-cancer-treatment）；应用未实现实时文献检索。

3D 形象：右下角使用 Three.js 实时渲染原创卡通模型，参考所提供图片的黑框眼镜、黑发、白大褂和蓝色领带，并非精确重建或真人克隆。支持待机呼吸、眨眼、目光跟随和思考动作；浏览器语音真正开始后触发示意嘴部动画（非音素级口型同步）。可暂停动作，尊重系统减少动态效果设置；WebGL 不可用时回退静态图片。对话功能及模型配置方式不变。
